# Game Name: Liminal Traverse

The scope of this game is to escape a dimension of liminality. You have to traverse a parkour scape called "The Cavern" and step up into the next level. 
 
The shard you collected has compressed your body to your true essence "a white block"

Now you either find all the falling shards or spend eternity traversing liminal landscape
